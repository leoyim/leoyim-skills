# Any-Subject Comic Poster

English | [简体中文](README.md)

A compact reusable skill for turning reference images of cats, animals, people, or characters into consistent comic-collage posters.

## Features

- Automatically identifies the subject in the reference image (species/person identity, fur/skin colors, markings, facial features) without assuming any particular species
- Produces a 9:16 vertical poster: one photorealistic central hero subject surrounded by 5–7 black-and-white comic panels (same subject, varied expressions)
- Keeps bold ink borders, halftone shading, speed lines, red hearts, yellow lightning bolts, and "OMG!" / "SO CUTE!" speech bubbles
- Ships with a complete default image prompt; supports custom aspect ratio, mood, outfit, and text language

## Install

Copy the `any-subject-comic-poster-skill/` folder into the skills directory used by your agent. The exact location depends on the platform — e.g. the user-level skills directory `~/.workbuddy/skills/` in WorkBuddy.

See [SKILL.md](SKILL.md) for the skill definition.
