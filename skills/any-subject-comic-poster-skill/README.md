# Any-Subject Comic Poster（任意主题漫画海报）

[English](README.en.md) | 简体中文

一个轻量可复用的 Agent 技能：把任意参考图（猫、动物、人物、虚构角色）转换为主体身份与特征保持一致的漫画拼贴海报。

## 功能

- 自动识别参考图中的主体（物种/人物身份、毛色、花纹、五官特征等），不预设任何物种
- 生成 9:16 竖版海报：中央为写实 hero 主体，四周环绕 5–7 个黑白漫画分镜（同一主体、不同表情）
- 保留大胆墨线边框、网点阴影、速度线、红色爱心、黄色闪电及 "OMG!" / "SO CUTE!" 对话气泡等漫画元素
- 内置完整默认图像提示词，支持自定义比例、情绪、服装与文字语言

## 安装

将 `any-subject-comic-poster-skill/` 文件夹复制到你所用 Agent 平台的技能目录。具体路径取决于平台，例如 WorkBuddy 的用户级技能目录 `~/.workbuddy/skills/`。

技能定义见 [SKILL.md](SKILL.md)。
